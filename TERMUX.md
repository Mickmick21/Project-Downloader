
# Termux
Termux is a Terminal Emulator for Android that doesn't require root or Shizuku.
Project Downloader fully supports Termux, so you can use Project Downloader on your phone.
To make setting up necessary dependencies, with only a few commands, everything will be set up.

Run `curl -O https://raw.githubusercontent.com/Mickmick21/Project-Downloader/refs/heads/main/termuxsetup.sh`.
Then run `chmod +x termuxsetup.sh` and then `./termuxsetup.sh`.

Then, to use Project Downloader, run :
`~/Project-Downloader/project-downloader.sh`.

Downloaded projects will be available under Termux in the Stock Android files app.
